# 守护 · shouhu

> **智能手机不该是终点，而应该是更好的开始。**
> **最好的守护，从来不是科技，而是陪伴。**

把一部安卓手机，变成老人手里"只会打给家人"的手机：桌面上只留家人允许的几个入口，
退不出去、误触不了；家人这边能远程看位置、看他有没有按时起床、把配置改回去。

代码全在自己手里，数据全在自己家里，没有账号、没有云服务、没有按月付费。

## 它解决什么问题

给老人换智能机，常见的四个坎：

| 坎 | 表现 | 这里的做法 |
|---|---|---|
| 桌面太乱 | 几十个图标，找不到电话 | 接管桌面，只留家人挑的几个大卡片，字体大、点击区大 |
| 容易退出 | 手一滑回到系统桌面，或者点进设置 | 锁定任务模式（Device Owner），HOME/返回都退不出去 |
| 找不到人 | 电话不接、出门没带、摔了 | 家人端查位置、看电量、看最后上报时间；失联会标出来 |
| 不会设置 | 让老人自己调，越调越乱 | 家人在自己手机上改，命令下发到老人机；改错能一键恢复 |

它**不是**监控软件：不开摄像头、不录音、不读聊天记录，只做定位、状态和桌面约束这几件事。

## 三个部件

| 部件 | 形态 | 跑在哪 | 作用 |
|---|---|---|---|
| **老人端** | 安卓 App（`com.elder.launcher`） | 老人的手机 | 守护桌面 + 定位上报 + 执行远程命令 |
| **家人端** | 安卓 App / 网页 | 家人手机、浏览器 | 看位置、看状态、改配置、扫码配老人端 |
| **中继** | 单文件 Go 服务 | 飞牛 NAS / Docker / OpenWrt 路由器 | 收老人端上报、给家人端查，兼做命令队列 |

中继不是必须的：老人端也能直连家人端（局域网/内网穿透），但有了中继，
老人端只要往一个固定地址上报，家里几台手机都能看，换手机不用改老人端。

## 快速开始

### 1. 起一个中继（三选一）

```bash
# Docker（最省事）
docker run -d --name shouhu-relay --restart unless-stopped \
  -p 8898:8898 -v $PWD/relay-data:/data \
  ghcr.io/your-name/shouhu-relay:latest
```

- Docker / Compose：[docs/36-Docker部署.md](docs/36-Docker部署.md)
- 飞牛 NAS（fpk 应用）：[docs/17-飞牛中继部署手册.md](docs/17-飞牛中继部署手册.md)
- OpenWrt / ImmortalWrt 路由器：[docs/33-OpenWrt插件.md](docs/33-OpenWrt插件.md)

起来后浏览器打开 `http://<地址>:8898`，进「中继页」先设访问密码，再加一位老人。

### 2. 装老人端

```bash
# 电脑连上手机（开 USB 调试），一条命令部署
tools/provision.ps1 -All
```

装完会接管桌面（Device Owner + 锁定任务）。没有电脑的，可以只装 APK 手动授权，
但**不激活 Device Owner 就锁不住桌面**，效果会差很多。

### 3. 装家人端 / 或用网页

家人端 APK 扫码即用；不想装 App 就打开中继首页，网页版功能一样。

## 能力清单

**老人端**
- 守护桌面：时间/农历/天气 + 大卡片（电话、微信、视频、家人照片）
- 锁定任务：HOME 退不出去，通知栏收起来，误触进不了设置
- 定位上报：定时上报位置/电量/网络/是否在充电，断网自动补发
- 远程命令：查位置、锁屏、调音量、报时、重启、恢复配置、抓快照
- 守护自检：9 项权限逐条判绿，缺哪项一眼看到

**家人端**
- 位置与轨迹、电子围栏（进出提醒）
- 电量、屏幕使用、最后上报时间（判断"是不是真的失联"）
- 卡片管理、头像/照片、音量与铃声、远程重启
- 扫码添加老人，配置一次不用再动

**中继**
- 多个老人、多个家人，令牌隔离
- 秒级通道（长轮询），命令不用等下一轮上报
- 轨迹留存（默认 90 天，可调），快照与回滚
- 网页管理台：设备、二维码、密码、在线检查新版本
- 一份代码四种部署：Docker / 飞牛 fpk / OpenWrt ipk / 裸二进制

## 设计取舍

几个刻意的"不做"，比做了什么更能说明它想成为什么：

**不做账号、不做云。** 中继跑在你自己家的 NAS 或路由器上，数据不出门。
代价是要自己部署一次；换来的是没有注册、没有订阅、没有"服务停止运营"。

**不做自动升级下发。** 中继只提示"有新版本"，绝不自己替换自己。
自动升级失败一次，可能就是全家人联系不上老人的一整天 —— 这个险不值得冒。

**协议只加不改。** 新中继永远兼容旧的老人端和家人端。
家人端不一定有条件经常更新，一次装好就该一直能用（见 [docs/37-版本兼容策略.md](docs/37-版本兼容策略.md)）。

**远程配置走"一次性拉取"，不走"持续下发"。** 改配置是低频动作，
做成常驻的配置通道，出 bug 时全家都动不了；做成一次性命令，坏了至少还能打电话。

## 安全边界

- 老人端需要 **Device Owner**（设备所有者）权限才能锁住桌面。这会改变手机的管理方式，
  请只用在**自己家的手机**上，并在装之前告诉老人。
- 中继有访问密码就一定要设：首页能看到所有老人的上报令牌，等于总钥匙。
- 二维码里带设备令牌，不要发到公开群里。
- 本项目不提供任何绕过他人设备的手段，也不做后台隐蔽运行；所有权限都在桌面「守护自检」里明示。
- 各厂商（华为/荣耀等）对第三方桌面有额外限制，需在系统设置里手动放行，
  具体见 [docs/34-手机兼容性.md](docs/34-手机兼容性.md)。
