# 没有数据流量时，还能定位吗？

结论先说：**能，但要分四件事看，缺流量只影响其中两件。**

| 环节 | 需要数据吗 | 说明 |
|---|---|---|
| GPS 卫星定位（取经纬度） | **不需要** | 手机只听卫星信号，纯接收。所以关掉移动数据、没 WiFi，只要有 SIM 卡有信号（甚至飞行模式下靠近窗边也能试），GPS 照样能出坐标 |
| 网络定位（基站 / WiFi 辅助） | **需要** | 关掉数据后基本失效。室内没有 GPS 时，这是唯一的救命通道，所以室内+无网=定不到 |
| 反查中文地址（"XX 省 XX 市 XX 路"） | **需要** | Geocoder 要联网。没网时我们直接跳过（省 5 秒），只发经纬度 |
| 发短信把位置发出去 | **不需要** | 短信走的是信令通道，和流量是两回事。只要卡有信号、没欠费、短信功能正常，就能发 |

## 三个容易被忽略的细节

**1. GPS 冷启动在没有网络时会明显变慢**

有网时手机用 A-GPS：先从网络下载星历（卫星"时刻表"），几秒就能定位。
没网时只能从卫星慢慢收星历，**冷启动 30 秒～几分钟**，第一次定位尤其慢。

所以这轮改了：检测到没有网络，就把等待时间从 25 秒放宽到 **60 秒**（多等 35 秒），
通知栏也会写"没有网络，正在等 GPS 定位（可能要一分钟）"。
家人既然已经响电话挂了，多等这一分钟是值得的——总比回一条"定位失败"强。

**2. 室内基本没戏**

GPS 信号穿不了屋顶。老人在家、又没网，大概率只能拿到"最后一次已知位置"。
这种情况短信里会明确写「（最后一次已知位置）」，不会让你误以为是实时位置。

**3. 短信里的高德链接，家人自己需要网络**

老人机把坐标和高德链接发出来不花流量，但**家人点开链接看地图要自己手机有网**。
坐标本身（经纬度 + 地址）是纯文字，没网也能读。

## 这轮为此做的四个改动

| 改动 | 原因 |
|---|---|
| 无网络时定位等待 25s → 60s | 纯 GPS 冷启动 25 秒经常一个点都拿不到 |
| 无网络时跳过 Geocoder 反查 | 本来必然失败，还白等 5 秒超时 |
| 短信里加精度提示（精度 > 120 米时写"可能不在室外"） | 避免家人把粗定位当成精确位置 |
| 通知栏区分"有网/没网" | 家人（或运维）一眼看出是网络问题还是 GPS 问题 |

## 什么情况下一定不行

| 场景 | 结果 |
|---|---|
| 手机没装 SIM 卡 / 没信号 | 短信发不出去，但 **GPS 仍能定位**（只是没人能收到），轨迹还会记在手机里 |
| 飞行模式 | 同上；轨迹仍在记，等有网/回家连 WiFi 后家人能拉到 |
| 欠费停机 | 短信可能发不出；GPS 正常 |
| 定位总开关关掉 | 彻底不行，这是权限层面 |
| 室内 + 无 WiFi + 无数据 | 只能拿到上次的缓存位置（会标注） |

## 一个务实的建议

真正可靠的组合是「**短信兜底 + 轨迹补历史**」：

1. 老人机没网时，家人响两声挂断 → 拿 GPS 定位 → 短信发回（这条链路不依赖任何服务器）
2. 同时老人机在本地每 10 分钟记一个轨迹点（也不依赖网络）
3. 等老人回家连上 WiFi（或者家人下次能连上它），家人端点开 App 自动同步，把这段时间的路线补出来

也就是说：**没网不会让"知道老人在哪"这件事断掉，只会让它是"延迟的"**。
