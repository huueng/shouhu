# 21 · 电脑端：装不上、解不开、批量装卸（2.6.3）

> 实测设备：荣耀 TNY-AL00（EMUI 10 / Android 10），Device Owner 已激活。
> 这一版把「一键部署卡住」「解锁解不开」两个老问题从根上处理了，并加了批量装卸和卸载守护。

## 一、"一键部署"为什么卡在安装

**实测复现**：`adb install` 发出后手机弹出「不允许执行此操作 —— 此操作已被禁止执行，请与贵单位的管理员联系」，电脑端就一直等，看起来卡死。

原因是 Device Owner 下发了 `DISALLOW_INSTALL_UNKNOWN_SOURCES`（设置里「禁止安装未知来源应用」打开时）。
两条路径都会被拦：

```
adb install -r app.apk            → 弹窗 + 无返回
adb shell pm install -i com.android.vending …  → 同样被拦
```

而且这条限制**只能由 Device Owner 自己清除**，外部 adb 没有对应命令 —— 这就是为什么手工点一下开关立刻能装，脚本却怎么都装不上。

**做法**（老人端新增 `AdminCommandReceiver`，电脑端按顺序处理）：

1. 安装前先问一次状态：`status` → `blockInstall=True`
2. 有拦截就先放开：`allow_install`（应用自己 `clearUserRestriction`）
3. 再装
4. 装完立刻收回：`restore_install`（恢复「禁止安装」，不给老人留口子）

实测输出：

```
[!] 手机当前状态：do=true blockInstall=true blockUninstall=true lockTask=false
[!] 这台手机开着「禁止安装未知来源」，装之前会自动临时放开，装完再收回。
[!] 检测到手机开着「禁止安装未知来源」，先临时放开…
[OK] 安装成功：elder-guardian-2.6.3-release.apk
```

装完再查状态，`blockInstall` 已自动变回 `true`。

**另一种卡住**：华为/荣耀纯净模式的「是否允许安装」弹窗没人点，`adb install` 会一直挂着。
现在安装带 **180 秒超时**，超时会直接说清原因，不再无声卡死：

```
[X] 安装超时（3 分钟没返回）
[!] 多半是手机弹了「纯净模式 / 是否允许安装」，没人点它就一直等。
```

## 二、"应用解锁"为什么解不开

原来 `-Unlock` 有四个问题：

| 问题 | 后果 |
|---|---|
| 最后一步 `pm disable-user` 禁用本应用 | 解锁后应用图标直接消失，看着就像"没解开" |
| 没恢复默认桌面 | 桌面仍指向守护（或被禁用的包）→ 黑屏 / 进不去桌面 |
| `settings delete` 整个键 | 把别人的无障碍、通知监听一起删了 |
| 用 adb `dpm remove-active-admin` 移 DO | EMUI 上经常失败，DO 还在，限制就还在 |

**新流程**：

1. 应用自己 `unlock_all`：放开安装/卸载、取消状态栏屏蔽、关锁定任务
2. `am force-stop`
3. **默认桌面换回系统桌面**（自动找非本应用的 HOME 组件）
4. 应用自己 `clear_owner`（`dpm.clearDeviceOwnerApp`，只有 DO 自己能做）
5. 只撤掉本应用那一条无障碍 / 通知监听记录
6. `pm enable` 确保应用是启用状态
7. 明确提示：**部分状态要重启才彻底生效**

**关于"是不是要重启"**：是，确实有四项要重启才落地 ——

- 默认桌面解析（换回后桌面图标可能还是旧的）
- 屏幕固定 / 锁定任务残留
- 被 `pm hide` 隐藏的包
- 状态栏禁用

所以解锁/卸载的最后都会写一句：需要的话点「重启手机」，别只看界面没变就以为没解开。

## 三、"解锁并卸载守护"（新按钮）

在「部署」卡片里，红色警告确认后执行：放开限制 → 换回系统桌面 → 清 Device Owner → 卸载。

会丢掉手机上的所有守护配置（锁定开关、桌面卡片、上报地址），且 **Device Owner 移除后必须恢复出厂才能重新激活**。

如果卸载仍提示 `DELETE_FAILED_DEVICE_POLICY_MANAGER`，说明 DO 没清干净：重启手机再执行一次，或手机上「设置 → 安全 → 设备管理器」取消勾选后手动卸载。

## 四、批量装卸第三方软件（新功能）

「应用管理（批量装卸软件）」→ 独立窗口：

- 列出**所有第三方应用**（不含系统预装），带版本号，勾选框
- 守护自己和家人端会标「守护自己 / 家人端」
- **卸载选中**：一次卸多个；有「禁止卸载」限制时会先临时放开
- **安装 APK…**：可多选文件，逐个装（同样走安装限制放行 + 超时）

实测：这台机器上读到 39 个第三方应用。
守护自己不能在这里卸（会提示用「解锁并卸载守护」）。

## 五、ADB 管理通道（给排障用）

老人端新增一个只有 adb 方便调用的广播口，命令都用同一个 action：

```
adb shell am broadcast -a com.elder.launcher.ADMIN \
    --es cmd <命令> --es k elder-adb --include-stopped-packages
```

| 命令 | 作用 |
|---|---|
| `status` | 回一行：`do=true blockInstall=true blockUninstall=true lockTask=false` |
| `allow_install` | 放开「禁止安装未知来源」 |
| `restore_install` | 收回 |
| `allow_uninstall` | 放开「禁止卸载」（含本应用防卸载） |
| `restore_uninstall` | 收回 |
| `unlock_all` | 放开安装/卸载 + 取消状态栏屏蔽 + 关锁定任务（**不动 Device Owner**） |
| `clear_owner` | 应用自己清掉 Device Owner（**不可逆**，只在卸载/解锁流程里用） |

安全边界：它只能放宽/收紧本应用自己设的限制，读不到位置、发不了短信；而且限制开着时本来也装不进新应用，能发这个广播的只有已经拿到 adb 的人。仍加了 `k` 校验防误触。
