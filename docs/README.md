## 关于截图

仓库里**没有放界面截图**。这类 App 的截图很容易把老人姓名、头像、家庭住址、
对外域名一起拍进去，所以截图只在本地留存。

想给 README 补图的话，请用测试数据重拍（假地址、假名字），并在提交前逐张看过：

- 地图页：不要出现真实村庄/小区名、真实坐标
- 设备页：不要出现真实域名和端口
- 详情页：不要出现真实姓名与头像照片
