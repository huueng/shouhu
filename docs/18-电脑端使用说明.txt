老人守护 · 电脑端使用说明（草稿版）
========================================

这个程序还没完工，先给个最短的上手流程。以后会补详细的。


一、这个程序是干什么的
----------------------
一个不用安装的 exe，双击就开。里面已经塞好了三个安装包：

  · 老人端（装在老人手机上）
  · 家人端（装在家人手机上）
  · 中继（装在飞牛 NAS 上）

窗口里能干的事：

  · 一键部署：装老人端 + 装家人端 + 激活设备所有者 + 授权 + 自检
  · 导出到电脑：把这三个包拷出来，方便发微信或装到别的电脑
  · 查老人机：看位置、看电量
  · 应急解锁：万一锁死了，一条命令把限制全解开


二、第一次用（装老人机）
------------------------
1. 手机连电脑（数据线），手机上选「传输文件」
2. 手机打开：设置 → 关于手机 → 连点「版本号」7 次 → 返回看到「开发者选项」
3. 开发者选项里打开「USB 调试」
4. 电脑上双击「老人守护电脑端.exe」
5. 看到「设备：xxx」说明连上了，点蓝色大按钮「一键部署」
6. 等它跑完（1～3 分钟），看下面的日志

一键部署现在是六步：装老人端 → 装家人端 → 激活设备所有者 → 一键授权 →
**屏蔽系统更新** → 自检。

日志里带 [X] 的行才需要处理，[OK] 是已经好了。


三、系统更新要不要关？（建议关）
--------------------------------
老人机最怕的不是耗电，是"半夜自己升级完"。升级以后常见的三件事：

  · 锁定任务白名单被重置 → 老人能退出守护界面
  · 无障碍、通知使用权被收回 → 看门狗和短信提醒失效
  · 桌面被换回系统桌面

第二天开机，老人发现手机"变回原来的样子"，就是升级干的。

所以有个单独按钮「屏蔽系统更新」。它会按品牌找到对应的更新程序关掉：

  华为 com.huawei.android.hwouc      荣耀 com.hihonor.ouc
  小米 com.android.updater           OPPO com.oplus.ota
  vivo com.vivo.upgrade             三星 com.wssyncmldm

只关手机里确实存在的那个，不动别的。想恢复就点「解除更新屏蔽」。

注意两点：
  · 个别机型重启后会自己把更新程序装回来，隔段时间看一次「守护自检」里
    的「系统更新」那一行，显示「已屏蔽」才算数。
  · 关掉更新不是"永不升级"。真要升级时先点「解除更新屏蔽」，升完重新
    跑一遍「一键部署」和「锁定任务」。


四、装家人端
------------
家人手机也一样：连电脑 → 点「只装家人端」。
不方便连线的话，点「导出到电脑」，把 APK 发到家人微信，手机上点开安装。


五、中继装到飞牛上
------------------
这台电脑不负责装 NAS。点「导出到电脑」，把 elderrelay-x.x.x.fpk 拷到 NAS，
在飞牛「应用中心 → 右上角设置 → 手动安装应用」里选它。
具体见 docs\17-飞牛中继部署手册.md。


六、配好之后怎么用
------------------
老人机上：
  设置 → 定位和传输 → 主动上报 → 扫一扫（扫中继网页上的二维码）
  间隔选 10 分钟，勾上「开启主动上报」

家人手机上：
  打开「守护同步端」→ 添加 → 扫码（扫中继网页上那位的二维码）
  点「后台提醒：开」，之后关掉 App 也能收到围栏提醒


七、如果这台不插卡（只连家里 WIFI 看视频）
--------------------------------------------
有些家里的情况是：老人自己用老年机打电话，另外放一台智能机，不插卡，
只连家里一两个 WIFI 刷视频。这台机器按下面的步骤开一下就行：

  老人端 → 时间连点 8 次进设置 → 「内网 WIFI 模式」→ 打开开关

打开后：

  · 桌面上「打电话 / 发短信 / 联系人」三张卡片消失
  · 顶部原来的手机信号格，变成 WIFI 名字 + 几格
  · 短信查询、响铃挂断定位、来电播报全部停用
  · 定位、轨迹、主动上报照常走 WIFI（IPv6 也支持）

然后配白名单：设置 →「家里 WIFI」→「把当前 WIFI 加进来」。
换路由器记得把旧名字删掉。

连错网（连到邻居家、公共网络）时，主界面顶上会出现红条并念一句
「网络连错了」；半小时只念一次。家人端「体检」里也会标红。

配完点「网络体检」看一眼 IPv6：
  显示 2408: 开头的一串 → 通的
  显示「没有」→ 去路由器/光猫里把 IPv6 打开，否则上报发不出去

详细说明见 docs\19-内网WIFI模式.md。


八、常见问题
------------
· 提示「没有检测到手机」
  换根线试试（很多线只能充电不能传数据）；或者在手机上把 USB 模式改成「传输文件」。

· 点「一键部署」后卡在安装，手机上弹「不允许执行此操作」
  这是 Device Owner 的「禁止安装未知来源」在拦。现在一键部署会自动处理：
  先问状态 → 临时放开 → 安装 → 装完自动收回，日志里能看到这几行。
  如果还是装不上，多半是手机上弹了纯净模式确认框没人点（现在 3 分钟会超时提示）。

· 点「应急解锁」后感觉没解开
  现在解锁会：放开限制 → 停掉应用 → 默认桌面换回系统桌面 → 清掉设备所有者 → 恢复应用启用状态。
  但默认桌面、屏幕固定、状态栏这几项，部分手机会要重启才彻底生效。
  所以解锁/卸载完请点一次「重启手机」，别只看界面上没变就以为没解开。

· 想把守护整个卸掉
  点「解锁并卸载守护」。会先解除限制和默认桌面再卸，卸完建议重启一次。
  注意：设备所有者被移除后，必须恢复出厂才能重新激活。

· 想批量删装手机上的软件
  点「应用管理（批量装卸软件）」：列出所有第三方应用（带版本），勾一下就能批量卸载；
  「安装 APK…」可以一次选多个包。守护自己不能在这里卸。

· 上报一直失败，想当场验一次
  先看失败原因：
    HTTP 401 令牌不对     → 中继那边重新生成过令牌，用 -SetUrl 写新的
    域名解析不了          → 路由器 DNS 不返回 AAAA，换 223.5.5.5 / 2400:3200::1
    连接超时              → 端口没放通，或者中继没起来
  验一次：
    tools\provision.ps1 -Report          立刻上报，结果直接打印
    tools\provision.ps1 -SetUrl "https://域名:812/api/report?k=令牌"   直接写地址
    tools\provision.ps1 -Info            看地址/开关/待补发（手机端命令，见 docs/23）

· 想改这台手机的用途（老人主手机 ↔ 只看视频机）
  tools\provision.ps1 -Intranet on|off  切「内网 WIFI 模式」
  tools\provision.ps1 -Setup            重跑「选形态 → 向导」

· 华为/荣耀装不上，提示「纯净模式」
  手机上选「仍然安装」。本程序的包是正式签名的，不是测试包。

· 点「一键部署」后「激活设备所有者」失败
  正常。设备所有者只能在新机（没登录账号、没设密码）上激活一次。
  已经用过的手机跳过这步就行，其他功能照常。

· 忘了老人机的锁屏密码 / 被锁在外面
  点「应急解锁」。

· 双击后窗口一直没出来
  说明启动那一步出问题了。看这个文件：%TEMP%\guard-launcher.log
  临时办法：用项目里的 tools\电脑端.bat 启动，效果一样。

· 360 / 火绒 之类的安全软件拦了
  这个 exe 没有代码签名，又是个自解压包，容易被当成可疑文件。
  处理办法：加到信任区（白名单）再双击。它做的事很简单——
  解压到临时目录、跑一个 PowerShell 脚本、弹个窗口，不写注册表、不装服务。
  以前的版本用过 VBScript 启动器，那个更容易被拦，现在已经不用了。

· 提示「屏蔽系统更新」后，手机还能收到更新提示
  说明这台机器的更新包名不在这份清单里。在手机上执行：
    adb shell pm list packages | findstr /i update
  把结果发过来，加进清单就行。

· 导出的安装包放哪了
  默认在桌面上的「老人守护安装包」文件夹里。
