# 换机兼容性审计（不限于荣耀 10）

> 目的：这套东西不只在一台手机上用。这份文档回答一个问题——
> **换一台手机（别的品牌、别的 Android 版本），哪些功能照样能用，哪些要额外做一步，哪些做不了。**

---

## 一、一句话结论

**核心能力（装、锁、打电话、短信定位、远程查位置、家人端）在任何 Android 6.0+ 的手机上都能跑**，
因为它们靠的是 Android 的标准接口（Device Owner + 无障碍 + 短信），不是华为的私有能力。

**真正会变的只有三件事**：① 谁能当默认桌面（各家策略不同，但我们本来就不依赖它）；
② 系统允许不允许 App 开关 WiFi/移动数据（Android 10 起都不允许，全品牌一致）；
③ 各家的"省电/自启动"策略，需要一次性手动放行。

---

## 二、三类能力，先分清

| 类别 | 含义 | 例子 |
|---|---|---|
| **A. 通用** | 标准 API，任何 Android 6+ 都一样 | 锁定任务、禁止安装、短信收发、GPS 定位、TTS、通知监听、无障碍 |
| **B. 看系统版本** | 同一品牌不同版本行为不同 | WiFi 开关（≤9 可用 / 10+ 收回）、按应用断网（11+ 才有）、前台服务、通知渠道 |
| **C. 看品牌** | ROM 自己加的限制，需要人工放行或用别的方式绕过 | 默认桌面白名单、自启动、后台弹出界面、纯净模式、无障碍被自动关闭 |

C 类是唯一"换机要重新摸一遍"的部分，下面逐项列。

## 三、逐项对照表

| 功能 | 靠什么实现 | 华为/荣耀 | 小米/Redmi | OPPO/vivo/一加 | 三星 | 原生 AOSP | 换机要做什么 |
|---|---|---|---|---|---|---|---|
| 装成桌面 | 锁定任务（LockTask） | ✅ 实测 | ✅ 一般可用 | ✅ | ✅ | ✅ | 无（不用改默认桌面） |
| 设成默认桌面 | `set-home-activity` | ❌ 拒绝 | ⚠️ 部分允许 | ⚠️ 部分允许 | ✅ | ✅ | 不用管，锁定任务已等价 |
| 禁止安装/卸载 | Device Owner | ✅ | ✅ | ✅ | ✅ | ✅ | 需激活 DO |

## 四、各品牌首次部署的"额外三件事"

这三件事**任何品牌都可能遇到，只是入口不同**，`provision.ps1 -Permissions` 只能解决其中一部分
（电池白名单、无障碍、通知使用权），剩下两项必须人工点：

| 要放行的项 | 小米/Redmi | OPPO/一加/realme | vivo/iQOO | 华为/荣耀 | 三星 |
|---|---|---|---|---|---|
| **自启动** | 安全中心 → 应用管理 → 权限 → 自启动 | 手机管家 → 权限隐私 → 自启动 | i管家 → 应用管理 → 自启动 | 应用启动管理 → 手动管理（三个开关全开） | 不需要 |
| **后台弹出界面** | 应用信息 → 其他权限 → 显示在其他应用上层 / 后台弹出界面 | 权限 → 悬浮窗 + 后台弹出 | 权限 → 后台弹出界面 | 悬浮窗 + 关联启动 | 不需要 |
| **省电策略无限制** | 应用信息 → 省电策略 → 无限制 | 耗电管理 → 允许后台运行 | 电池 → 后台高耗电 → 允许 | 电池 → 应用启动管理 → 手动 | 电池 → 不受限制 |
| **纯净模式 / 安装拦截** | 需关"MIUI 优化"或允许安装未知应用 | 需关"安装校验" | 需允许安装 | **纯净模式必须关**（否则装不上 release 包） | 需允许未知来源 |

> 这一段建议直接做成"部署卡"打印出来，第一次给家人装的时候照着点一遍。

## 五、这轮为"换机"做的三处加固

### 1. 通话界面改成按能力解析，不再写死包名
以前白名单里写的是 `com.android.incallui`。换到三星就是 `com.samsung.android.incallui`，
换到某些小米机型是 `com.miui.incallui`——**写死包名就会重现"通话没有界面"那个 BUG**。

现在改成：

```java
// 谁声明了 InCallService，谁就是画通话界面的
queryIntentServices(new Intent("android.telecom.InCallService"))
// 拨号/通话/短信/会话列表：把每个 Intent 的所有候选都放进去
queryIntentActivities(ACTION_DIAL / ACTION_CALL / SENDTO smsto: / mms-sms)
```

实测白名单从 21 个涨到 **26 个**（多出来的就是按能力解析到的），荣耀 10 上通话页依旧正常。

### 2. 家人端两列布局加老 WebView 兜底
家人端是 WebView + 本地 HTML。**Android 6/7 的 WebView 版本可能低到不支持 CSS grid**，
格子会变成"一张卡占满整行"。现在先写 flex，支持 grid 的再用 `@supports` 覆盖——两代都能两列。

### 3. 家人端 JS 全程 ES5
检查过：没有箭头函数、没有模板字符串、没有 let/const。老 WebView 也能跑。

## 六、换机操作清单（照着做，20 分钟）

```
旧手机
 1. 设置 → 运维与迁移 → 导出配置（得到 profile-xxxx.json，在「下载/老人守护」里）
 2. 把这台手机上「远程访问」里的域名/密钥记下来（配置里也带着）

新手机
 3. 装 APK（release 包；华为先关纯净模式）
 4. 电脑上：tools\电脑端.bat → 激活设备所有者 → 一键授权
 5. 新手机上：设置 → 运维与迁移 → 导入配置（选第 1 步那个 json）
 6. 按第四节把自启动 / 后台弹出 / 省电策略放行
 7. 重启一次，确认开机直接进守护、HOME 退不出去
 8. 用另一台手机打进来，确认通话页出现、能挂断
 9. 发短信「诊断」，看回执里哪一项还是红的，按提示补
10. 家人端点「体检」，确认电量/信号/位置都正常
```

> 第 9 步是关键：**「诊断」这一条短信就是换机后的验收单**。
> 它会把设备所有者、锁定、无障碍、通知、电池白名单、定位、域名逐项列出来。

## 七、换机一定会失去 / 一定会遇到

| 项 | 说明 |
|---|---|
| Device Owner 丢失 | 卸载重装就没了，必须重新 `-Owner` 激活（所以换机前先导配置） |
| 首次发短信的 4 位验证码 | 新装后第一次自动发短信会要一次，属系统行为 |
| 锁定任务要重开 | 新机上默认是关的，避免一装就锁死 |
| 轨迹历史 | 只存在旧机本地，换机不迁移（需要就提前用家人端「拉取轨迹」拉走） |
| 无障碍被系统关掉 | 小米/OPPO 常见，随时发「修复」短信或重开 |

## 八、家人端（com.elder.family）兼容性

| 项 | 要求 | 说明 |
|---|---|---|
| 最低系统 | **Android 6.0（API 23）** | 与老人端一致 |
| 界面依赖 | 系统 WebView | Android 6/7 上已做 flex 兜底 |
| 地图 | 需要联网加载 Leaflet + 高德瓦片 | 首次要求联网；断网时提示"点高德打开" |
| 扫码 | 调系统相机拍一张再用 zxing 解 | 不依赖相机 API 预览，兼容性最好 |
| 头像 | 相册选图 → 压到 320px 存本地 | 不依赖任何第三方库 |

---

## 九、结论

- **换同品牌 / 原生 Android**：几乎零成本，装完走一遍第六节即可。
- **换小米/OPPO/vivo**：多一步"自启动 + 后台弹出 + 省电无限制"，其余一样。
- **换到 Android 11+**：多出「按应用禁流量」；**Android 9 及以下反而能直接开关 WiFi**。
- **换到 Android 14+**：需要升级 targetSdk（补 `<queries>`、前台服务 type），这是唯一需要改代码的版本门槛。
