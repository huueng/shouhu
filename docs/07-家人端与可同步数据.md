# 家人端能力与「还能同步什么」

## 一、这一版家人端有什么

| 能力 | 实现方式 | 状态 |
|---|---|---|
| 多个老人，一卡一人 | 本地存储 `elder_family_v2`，卡片列表点进去是详情 | ✅ |
| 添加方式 | 相机扫码 / **相册选图扫码** / 手动填写 | ✅ |
| 国内地图 | Leaflet + **高德栅格瓦片**（高德坐标系 GCJ-02），不需要 Key | ✅ |
| 定位 | 直接请求 `/loc?key=`，走域名（DDNS）或 IPv6 | ✅ |
| 电子围栏 | 设中心 + 半径，每次查询算距离，超出弹提醒 | ✅（查询时判断） |
| 路径 | 每查一次记一个点，最多 200 个；地图连线 + 累计里程 | ✅ |
| 短信查询教程 | 内置说明，不依赖网络 | ✅ |
| 一键跳高德 | `uri.amap.com` 深链 | ✅ |

### 电子围栏的真实边界（重要）

老人机的定位是「被问才取」，没有常驻推流。所以围栏不是服务端围栏，而是：

- 家人端**每次查询时**判断是否越界；
- 点「自动查（1 分钟）」后，App 开着就每分钟查一次，越界立刻提示；
- App 关掉就不查了（不耗电，但也盯不住）。

要真正的「进门就报警」，得让老人机主动上报，那就需要推送通道（短信或服务器）。目前最省事的方案是：**老人机侧加一个定时上报**（比如每 10 分钟 POST 一次到家里 NAS），这个可以下一步做。

## 二、还能同步什么数据

现在 `/loc` 只返回经纬度、精度、电量、时间。其实这些都能顺带加进去，**几乎零成本**（同一个 HTTP 响应里多几个字段）：

### A. 强烈建议加（成本低、家人真关心）

| 数据 | 怎么取 | 为什么值得 |
|---|---|---|
| 充电状态 / 是否插着充电器 | `BatteryManager` | 「电量正常掉」和「一直没充电」是两回事，没充电往往说明老人拔了充电器忘了插 |
| 屏幕亮着还是灭着 | `PowerManager.isInteractive()` | 判断老人在不在用、还是睡了 |
| 最后一次亮屏时间 | `UsageStatsManager` / 广播 | 「今天 9 点了还没动手机」比坐标更能说明异常 |
| 今日使用时长 + Top3 应用 | `UsageStatsManager` | 突然的「微信 0 分钟」就是异常信号 |
| WiFi 名称 / 是否用的移动数据 | `WifiManager` / `ConnectivityManager` | 判断在家还是在外；能直接支撑「到家报平安」 |
| 系统音量 / 是否静音 | `AudioManager` | 老人误按成静音，家人打电话永远没人接，这是真实高频问题 |
| 手机剩余存储 | `StatFs` | 存储满了会卡、相机打不开、微信报错，老人说不清楚 |

### B. 值得加（稍复杂）

| 数据 | 说明 |
|---|---|
| 步数 | `TYPE_STEP_COUNTER` 传感器，多数机器有；能画「今天走了多少」 |
| 陌生来电 / 被拦截短信数 | 需要通话记录权限（已有），可做反诈提示 |
| 锁定任务是否还生效 / 自检缺了几项 | 直接读本地状态，家人一眼看出「哪项被系统重置了」 |
| 应用版本号 | 远程判断要不要升级 |

### C. 不建议加（隐私或成本不划算）

| 数据 | 原因 |
|---|---|
| 通讯录 / 短信内容 | 隐私红线，家人之间也该有边界 |
| 实时屏幕画面 | 老人知道会不舒服；耗电、耗流量 |
| 心率 / 血压 | 手机测不准，别给假数据 |
| 常驻位置推流 | 耗电大，且违背「零服务器」的初衷 |

### D. 实现建议

新增一个 `/status?key=` 端点（和 `/loc` 平行），一次返回：

```json
{
  "ok": true,
  "battery": 73, "charging": true,
  "screenOn": false, "lastUnlock": 1792920000000,
  "wifi": "CMCC-1234", "mobile": false,
  "volume": 8, "muted": false,
  "storageFreeMB": 12480,
  "topApps": [{"pkg":"com.tencent.mm","minutes":22}],
  "health": {"lockTask": true, "missingChecks": []},
  "version": "2.0"
}
```

家人端点「体检」按钮一次拉完，卡片上就能显示「电量 73% · 在家 · 静音」这种一眼看懂的摘要。

定位和状态可以合成一次请求（`/loc` 返回里带 `status` 对象），少一次往返。

## 三、下一步优先级

1. `/status` 端点 + 家人端「体检」卡片（半天）
2. 音量/静音提醒（老人最常见的问题之一）
3. 存储余量提醒
4. 老人机定时上报（给真正实时的围栏铺路）
