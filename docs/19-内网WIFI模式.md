# 19 · 内网 WIFI 模式（不插卡的看视频机）

> 一句话：家里那台「只连 WIFI、不插卡、老人刷视频用」的智能机，
> 打开这个模式后，电话和短信整条线从界面和逻辑里撤掉，只留视频、定位和上报。
> **不设 WIFI 白名单**——连上哪个网都行，上报时只把 WIFI 名字带回去。

## 为什么单独做一个模式

原来一套 App 是按「老人主手机」设计的：有 SIM 卡、要打电话、收短信、响铃挂断查位置。
但实际使用里还有一种机器：

- 老人自己用**老年机**接打电话，智能机只是放在家里刷视频打发时间
- 智能机**不插卡**，连家里 WIFI（多数宽带带 IPv6）
- 这台机器不需要通知谁"来电话了"，但**必须能让家人知道它还在、人还在家**

强行把主手机那套塞给它，结果是：桌面上一堆点了报错的卡片（打电话、发短信、联系人），
设置页一堆永远为「无卡」的开关。

## 关于白名单（2.7 已去掉）

早期版本做过「家里 WIFI 白名单」：家人先配好允许连哪几个网，连错就红条 + 语音提醒。
实际用下来弊大于利：

- 配了没生效、换了网界面不刷新，反而更难排查
- 这种机器基本不离开家，白名单挡住的情况几乎不会发生

现在只做一件事：**读当前 WIFI 的名字，显示出来，上报时带上**。
判断"网络正常"的标准只有一条：**连着 WIFI**。

## 打开方式

两条路：

1. **首次装机**：警告页 →「这台手机怎么用？」→ 选「只连家里 WIFI，看视频用」→ 继续初始设置
2. **已经在用**：老人端 → 时间连点 8 次进「家人设置」→「内网 WIFI 模式」→ 打开开关

设置页里那一行现在显示「当前 WIFI：xxx（只记录名字，不限制连哪个网）」，点一下刷新。

## 打开后变了什么

| 项目 | 普通模式 | 内网 WIFI 模式 |
|---|---|---|
| 桌面「打电话」卡片 | 有 | **去掉** |
| 桌面「发短信」卡片 | 有 | **去掉** |
| 桌面「联系人」卡片 | 有 | **去掉**（通讯录管理入口一并隐藏） |
| 顶部信号格 / 运营商 | 手机信号 | **WIFI 名字 + 格数** |
| 短信指令（位置/诊断/修复…） | 可用 | **停用**（没卡收不到，逻辑直接返回） |
| 响铃挂断查位置 | 可用 | **停用** |
| 来电播报 / 通话结束回桌面 | 可配 | **隐藏** |
| 移动数据限制 | 可配 | **隐藏**（无卡无意义） |
| 短信定位 / 家人号码 | 可配 | **整组隐藏** |
| 定位服务、轨迹、主动上报 | 保留 | **保留**（走 WIFI / IPv6） |
| 网页传包、通知拦截、清理后台 | 保留 | **保留** |
| 锁定任务、禁装禁卸、看门狗 | 保留 | **保留** |

「无线网络」卡片仍然保留——这是这台机器唯一需要老人（或家人）操作的东西。

## 连不上网的时候

只在两种情况下出红条（点一下会再念一遍）：

- 「无线网络被关掉了，家人看不到位置」
- 「没连上 WIFI，家人看不到位置」

家人端「体检」里能看到 `内网 WIFI 模式（不插卡）　IPv6：…`，
没连 WIFI 时标红「没连上 WIFI」。正常连接时只显示 WIFI 名字，不再判断"是不是家里的网"。

## 上报带了什么

`status` 里本来就有 `wifiName`（系统给的 SSID），内网模式下另外三个字段：

- `intranet`：true
- `netFlag`：`ok` / `no_wifi`（只区分连没连上）
- `ipv6`：本机 IPv6 全局地址（家里只有 IPv6 时，这个比"WIFI 已连接"更能说明通不通）

## WIFI 页也一起修了

之前主界面点「无线网络」经常是空白列表，连不上网。查下来是三个原因：

1. 扫描结果只等系统广播，部分 ROM（含 EMUI）广播不按时发 → 现在自己轮询 5 次
2. 已经连上的那个网被 `continue` 跳过 → 现在第一条就显示「已连接：xxx」
3. 系统**定位总开关**关着时 Android 不给应用返回扫描结果，而界面只写「没搜到」
   → 现在直接说清原因，并给一个「去打开定位」按钮

另外空列表时还提供「打开系统 WLAN 设置」，实在搜不到可以直接去系统页连。

## 边界（先说清做不到的）

- **不能强制开关 WIFI**：Android 10 起系统不允许，只能引导去设置页。
- **不替代老年机**：这台机器没有卡，打不了电话。
- **短信兜底通道失效**：这个模式没有短信，只能靠中继/直连上报。中继地址必须在装机时配好。

## 自检和排查

- 「守护自检」里，普通模式的「短信收发权限」一项会换成「家里 WIFI」，
  没连上就算不通过，可以直接点进无线网络页。
- 手工排查顺序：设置 → 内网 WIFI 模式 →「网络体检」→ 看 WIFI 名 / IPv6 / 上报结果。

## 七、中继必须 ≥ 1.6.1（否则家人端看不到 WIFI 名字）

老人端一直都有把 `wifiName` 发出去，但**中继 1.6.0 及以前的报文结构里没有这个字段**，
解析时被静默丢掉，`/api/status` 也不输出 —— 家人端只能显示成「WiFi 」后面空着。

1.6.1 起：`Report` 增加 `WifiName / Intranet / NetFlag / Ipv6`，
`/api/status` 输出 `wifiName`（内网模式下再加 `intranet / netFlag / ipv6`）；
只报定位的包会沿用上一次的名字，不会把家人端刷成空。

实测返回：

```json
{"wifi": true, "wifiName": "FF", "intranet": true, "netFlag": "ok",
 "ipv6": "2408:8220:7f1e:5821:...", "battery": 55, "charging": true}
```

顺带一句：**不连 WIFI 也能上报**。只要手机的移动网有公网 IPv6（联通/移动/电信的 4G/5G 基本都有），
而中继域名只有 AAAA 记录时同样能解析 —— 实测移动数据下上报正常。

## 八、换模式不用手点

```
tools\provision.ps1 -Intranet on     # 切到内网 WIFI 模式
tools\provision.ps1 -Intranet off    # 切回老人主手机
tools\provision.ps1 -Setup           # 重跑「选形态 → 向导」
```

注意：用家人端「恢复布局」恢复基线时，**内网模式开关也会一起被恢复**（它在配置白名单里），
所以远程恢复完如果发现电话卡片回来了，是基线里当时就是正常模式，再 `-Intranet on` 切一次即可。
