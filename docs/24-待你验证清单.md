## 1. ★ 扫一扫（这次修的，最需要你确认）

路径：桌面连点时间 8 次 → 设置 → 定位和传输 → 主动上报 → **扫一扫**

| 检查 | 应该看到 |
|---|---|
| 点「扫一扫」 | **系统相机直接打开**（以前是点了没反应） |
| 对着中继网页上的「老人端」二维码，20–30cm | 拍完点「确定」→ 弹出「已扫码配置」+ 上报地址 + 正在测试 |
| 故意对着一面白墙拍 | 弹出「没识别出二维码」+ 距离/反光/取景三条提示 + 「再试一次」 |
| 扫一个普通网址的二维码 | 弹出「这个码不是上报地址」 |
| 扫完回桌面 | 桌面正常，电话/短信卡片没回来（相机只是被临时放行，已收回） |

> 相机打开但拍不了 / 拍完没弹框，请记下：相机界面截图 + 手机型号。

**如果扫不上但地址是对的**，可以验一下解码器本身坏没坏（把二维码截图发到手机）：

```
adb shell am broadcast -a com.elder.launcher.ADMIN --es cmd qrdecode --es arg "/sdcard/Download/二维码.png" --es k elder-adb --include-stopped-packages
```

- 回 `data="qr:https://…/api/report?k=…"` → 解码没问题，是拍的问题
- 回 `qr:no-qr` → 那张图没二维码或太小
- 回 `qr:not-image` → 路径不对

## 3. ★ 远程健康检测 / 恢复布局

家人端 → 选中老人 → 点「健康检测」

- 立刻：`已下发，等老人端下次上报执行（最多 10 分钟）`
- 等一个上报周期（或电脑上 `provision.ps1 -Report` 催一次），再点「体检」
- 应该看到：`上次远程命令：health → 成功　N 分钟前` + `10/10 正常`（缺项会写「缺：无障碍服务」这种）

「恢复布局」注意：**它会把上报地址也恢复成基线**。如果恢复完变成 `HTTP 401`，
说明基线里的令牌是旧的，再跑一次第 0.1 步就好。桌面卡片、锁定开关、内网模式都会回到基线那一刻。

「存快照」：点完等一个周期，体检里应出现「save → 成功」。

## 15. 第八轮（中继 1.12.0）：飞牛 APP 里能打开了

### 15.1 为什么之前打不开

之前 fpk 只声明了**端口入口**（`http://NAS:8898`），而飞牛 APP 里点图标走的是

两者不是一回事，所以 APP 里一直是白屏/打不开。

## 16. 第九轮（中继 1.13.0 / 老人端 2.15 / 家人端 3.0）

### 16.1 扫码：真凶是二维码太小

中继页面上的二维码原来只有 **180px 宽**，而那张码里塞了地址 + 令牌 + 名字 + 设备 id，
密到每个模块只有 4 个屏幕像素。手机对着屏幕拍，等于在拍马赛克 —— 这就是"怎么扫都扫不上"。

现在：

| 改动 | 之前 | 现在 |
|---|---|---|
| 二维码显示宽度 | 180px | **320px**（小屏自适应 86vw） |
| PNG 分辨率 | 560 | 900（高分屏更锐） |
| 码内容 | 带设备 id | 去掉没用到的 `d` 参数，模块更粗 |

另外两端解码器都加了三层：区域（整图/中心 70%/中心 45%/四象限）×
二值化（Hybrid/Global/Otsu）× 前置（原图/对比度拉伸/放大 1.8 倍/锐化）。
实测 17 个退化样本（旋转、模糊、缩小、反色、深底、JPEG q30…）从原来挂 4 个变成只挂 1 个
最极端的合成样本。

**还扫不上怎么办**：
- 家人端编辑页多了「从相册选二维码截图」，截图是 PNG，几乎必成
- 老人端失败对话框里会给出**照片留档路径**（`Android/data/包名/files/扫码失败/`），
  下次把那张图发我，就能判断是拍糊了还是码太小

## 18. 第十一轮（老人端 2.16 / 中继 1.14.1 / 家人端 3.2）

### 18.1 夜里失联（这次的重点）

不是断网，是**上报闹钟不会唤醒手机**（`ELAPSED_REALTIME` 非唤醒型），
深度睡眠时整夜不触发。轨迹时间戳里 11-12 00:06 → 11:10 空了 11 小时，
`dumpsys alarm` 里 `REPORT_TICK type=3 wakeup=false` 就是证据。

已改成 `ELAPSED_REALTIME_WAKEUP` + `setExactAndAllowWhileIdle`，触发后自动重排。
真机核对：`type=2 wakeup=true window=0`。

| 检查 | 应该看到 |
|---|---|
| 老人端设置里「上次上报」 | 隔一夜看，时间不应该停在 00:06 |
| 早上打开家人页 | 位置是新的，不再显示「超过 30 分钟没更新」 |
| 手机耗电 | 一晚上多 1%–3%（每 10 分钟一次心跳） |

**还要手动点两下**（厂商私有设置，程序改不了）：

- 设置 → 电池 → 启动管理 → 守护桌面：关「自动管理」，改成手动，允许自启动/后台活动
- 设置 → 电池 → 更多电池设置 → 休眠时始终保持网络连接：打开

细节见 `docs/32-夜间失联的原因.md`。

### 18.2 文案

家人页超过 30 分钟没更新时，不再一律说「可能断网了」，改成
「可能手机息屏没上报，或者网络断了」。
