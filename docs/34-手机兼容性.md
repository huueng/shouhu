# 换别的品牌手机行不行

现在只在华为 COL-AL10（EMUI 10）上完整跑过。下面是按代码和系统机制逐条推的结论，
不是"应该没问题"这种糊话——每条都标了依据和验证方法。

## 一、装得上吗？能。

- release 签名、非 `testOnly`，不会被"纯净模式"以调试包为由拦（华为那次就是被这个拦的）
- `minSdk 23`（Android 6.0）起，覆盖绝大多数在用机型
- **没有任何 Google 服务依赖**：只用了 androidx 三个库 + zxing，国产 ROM 完全不受影响
- 没有用厂商私有 API；华为的包名只是"放行白名单"里的字符串，没有的会被系统忽略

真正的门槛是**装完之后的权限和后台**，不是安装本身。

## 二、分品牌结论

| 品牌 / 系统 | 能装 | 设备所有者（关键） | 后台保活 | 结论 |
|---|---|---|---|---|
| 原生 / AOSP（Pixel、索尼、摩托、诺基亚） | ✅ | ✅ 直接成功 | 好 | **最省心，首选** |
| 三星 One UI | ✅ | ✅ 一般可行 | 中（要关"未监视的应用"休眠） | 可用 |
| 华为 EMUI / 荣耀旧机 | ✅ | ✅ 已验证 | 中（要改"启动管理"） | 可用 |
| 荣耀 MagicOS（新机） | ✅ | ⚠️ 部分机型拦 | 中 | 要试 |
| 小米 / 红米 MIUI、HyperOS | ✅ | ⚠️ 需先关"MIUI 优化" + 开"USB 调试(安全设置)" | 差（自启动默认关） | 可用但折腾 |
| OPPO / 一加 / realme（ColorOS） | ✅ | ⚠️ 部分版本 `set-device-owner` 报错 | 差 | 要试 |
| vivo / iQOO（OriginOS） | ✅ | ❌ 多数机型拒绝 | 差 | **不建议** |

"设备所有者"为什么是生死线：锁定桌面的实现是 `startLockTask()`。有 DO 时它静默生效；
**没有 DO 时系统会弹"屏幕固定"确认框**，还要用户手动点"固定"——老人不会点，
等于桌面锁不住，能直接退出去。所以非 DO 设备只能当"普通桌面"用，防护等于没有。

项目里已经有 `ElderDeviceAdminReceiver.isDeviceOwner()` 判断，不是 DO 时不会崩，
只是锁定功能降级；健康检测里会明确报"缺：设备所有者"。

## 三、每个品牌都要手动做的事

这些是系统级开关，`Device Owner` 也改不了（厂商私有），必须点一次：

### 1. 授予 `WRITE_SECURE_SETTINGS`（必须 adb）

```bash
adb shell pm grant com.elder.launcher android.permission.WRITE_SECURE_SETTINGS
```

`tools/provision.ps1 -All` 里已经包含。**换机后要重做一次**，因为这是按安装授权的。

### 2. 设备所有者（必须 adb，且设备上没有账号）

```bash
adb shell dpm set-device-owner com.elder.launcher/.ElderDeviceAdminReceiver
```

- 小米：设置 → 更多设置 → 开发者选项 → 打开「USB 调试(安全设置)」，并关闭「MIUI 优化」
  （关 MIUI 优化会重启，且部分系统应用行为变化）
- OPPO/realme：开发者选项里打开「禁止权限监控」，否则 dpm 命令会被拦
- vivo：多数机型直接返回 `Not allowed to set the device owner`，无解
- 已经登录了小米账号/Google 账号的设备会失败，要先移除账号

### 3. 无障碍服务（必须手动开）

设置 → 无障碍 → 已下载的服务 → 守护桌面 → 打开。

- MIUI / vivo 有"无障碍超时自动关闭"，要在开发者选项里关掉，否则过一会儿自己关
- 开了之后系统会提示"可能读取屏幕内容"，属正常

### 4. 通知使用权（来电播报要用）

设置 → 通知与状态栏 → 通知使用权 → 守护桌面 → 允许。

### 5. 悬浮窗（浮动导航条要用）

设置 → 应用 → 守护桌面 → 显示在其他应用上层 → 允许。

### 6. 使用情况访问（自动清理后台要用）

设置 → 应用 → 特殊权限 → 使用情况访问 → 守护桌面 → 允许。

### 7. 电池与自启动（夜里能不能上报就看这个）

- 电池优化白名单：设置 → 电池 → 电池优化 → 守护桌面 → 不优化
- **小米**：设置 → 应用设置 → 守护桌面 → 自启动（打开）、省电策略（无限制）
- **OPPO/一加/realme**：设置 → 电池 → 应用耗电管理 → 守护桌面 → 允许后台运行
- **vivo**：设置 → 电池 → 后台耗电管理 → 守护桌面 → 允许
- **三星**：设置 → 电池 → 后台使用限制 → 从不休眠的应用 → 加入
- **华为/荣耀**：设置 → 电池 → 启动管理 → 守护桌面 → 关"自动管理"，手动允许三项
- 通用：设置 → 电池 → 更多 → 休眠时保持网络连接（部分 ROM 有）

> 这一项不做，就会出现"夜里失联"——跟 11-12 那次一样（见 docs/32）。

## 四、代码层面已经处理过的兼容点

| 问题 | 处理 |
|---|---|
| 通话界面不是拨号器画的 | 锁定白名单里同时放 `incallui` / `telecom` / 各品牌包名，并且按 Intent 查**全部候选**，不写死 |
| 联系人/短信包名各家不同 | 按 `Intent.ACTION_VIEW` 解析实际应用后再放行 |
| 相机包名各家不同 | 扫码时动态解析 `ACTION_IMAGE_CAPTURE` 的包，临时加进锁定白名单，拍完收回 |
| 状态栏颜色 | 主题里显式给 `statusBarColor`，深浅色两套，不依赖 `colorPrimaryDark` |
| 通知渠道 | API 26+ 才建渠道，低版本走旧构造 |
| 精确闹钟 | API 23+ 用 `setExactAndAllowWhileIdle`，低版本 `setExact`，再低走 `set` |
| 没有 DO | 不崩，健康检测里报缺项，锁定降级 |

## 五、换机验收清单

按顺序走一遍，每步都有明确判据：

1. **装得上**：`adb install -r` 成功，桌面出现图标
2. **能设 DO**：`adb shell dpm list-owners` 有 `com.elder.launcher`
3. **权限齐**：设置页 → 健康检测 → 「10/10 正常」（缺哪项它会写出来）
4. **锁得住**：开启锁定后，按返回/主页退不出去；从最近任务划不掉
5. **电话能打通**：来电有界面、能接听、挂断回桌面
6. **上报正常**：设置页「上次上报」在 2 分钟内；中继 `/api/status` 能看到设备
7. **隔夜不断**：放一晚，早上看「上次上报」不是停在凌晨
8. **远程命令生效**：中继页点「健康检测」，几秒内回结果

任何一步不过，把型号 + 系统版本 + 那一步的现象发我，能定位到具体是权限还是 ROM 限制。

## 六、如果 DO 设不上（vivo 这类）

能用的部分：桌面、位置上报、家人端查看、远程命令（靠上报捎带）。

不能用的部分：锁定桌面（老人能退出）、禁装禁卸、隐藏状态栏。

折中办法：用系统自带的"屏幕固定"（设置 → 安全 → 屏幕固定），把守护桌面固定住。
缺点是需要人手动开启，且重启后失效，**不适合长期给老人用**。
