## P1 · 真机回归与稳定性（最紧迫）

这 7 项代码写完了但没在真机上跑过，**任何一项不通过都会让"守护"名不副实**，必须优先收口。

| # | 验证项 | 通过标准 | 失败预案 |
|---|---|---|---|
| P1-1 | 开机自启 + 自动锁定 | 重启后 30 秒内自动停在老人桌面，HOME 无效 | 若被后台启动限制拦住：改用 `LOCKED_BOOT_COMPLETED` + 前台服务 + 引导家人手动点一次 |
| P1-2 | 锁定任务下老人能否误退 | 连按 HOME/返回/多任务 20 次都退不出 | 检查 `setLockTaskPackages` 白名单是否被系统更新重置 |
| P1-3 | 悬浮导航键 | 三个键都能用，且锁定时不被遮挡 | 若无障碍被杀：加入"自愈"——每小时检查并提示家人 |
| P1-4 | 通知白名单 | 非白名单应用通知不出现，白名单正常 | 检查监听器绑定状态，必要时降级为"仅静音不拦截" |
| P1-5 | 周期清理后台 | 到点真的清掉，且不误杀微信/电话 | 把周期改为"仅亮屏且空闲时清理" |
| P1-6 | 短信定位 | 家人号码发"位置"能在 30 秒内收到定位短信 | 双卡/短信中心问题要单独排查 |
| P1-7 | 整点报时 / 天气播报 | 到点出声，锁屏也出声 | TTS 引擎缺失时给出"去安装讯飞语音引擎"引导 |

**P1 的产出**：一份《机型适配表》（华为/荣耀、小米、OPPO/vivo、原生），每格记录 9 项自检结果 + 特有坑。

## P2 · 家人侧可用性

目标：家人拿到一台新手机，**不看文档**也能在 5 分钟内配好。

1. **设置页加 PIN 锁**
   连点 8 次 → 输 4 位数字（家人自设）。防止老人自己乱点进设置改坏配置。目前只有隐藏手势，老人误触概率不低。
2. **桌面模板**
   预置三套卡片组合：`极简（电话+微信+短信）`、`常用（+支付宝+天气）`、`自定义`。家人点一下选模板，不用逐个勾。
3. **配置导入 / 导出（二维码）**
   一台机器配好后生成二维码，第二台机器扫一下就行。多老人家庭、换机场景直接受益。**不依赖服务器**，纯本地生成。
4. **自检页引导动画**
   现在点"去开启"直接跳系统设置，老人手机的设置路径和常人机不一样（华为叫"无障碍"、小米叫"更多设置"）。改成"跳转 + 截图指引 + 回来自动重检"。
5. **主界面空态处理**
   卡片少于 3 个时给家人一句提示（"桌面太空了，去设置里加几个应用"），避免装完一片空白以为是坏了。

## P3 · 远程运维（少发版的关键）

你明确偏好"远程配置、一次安装"，这一阶段就是把这个偏好落地：

1. **配置下发三条腿**（按可用性排序，都不需要自建服务器）
   - 二维码 / 本地文件（家人当面配）
   - 短信指令配置（发一条模板短信，App 解析后写配置）——复用现有 `SmsCommandReceiver`
   - 可选：一个静态 JSON（放 OpenList / 对象存储 / Gitee raw），App 每小时拉一次
2. **状态回传**
   家人发"状态"→ 回一条短信：在线状态、电量、最近 1 小时用了哪些 App、自检缺哪几项。这是"远程运维"的最小闭环。
3. **远程解锁码**
   老人在外地被锁死、家人不在身边时，发一条带口令的短信临时解除锁定 30 分钟。
4. **批量部署**
   `provision.ps1` 加 `-Csv devices.csv` 模式，一次刷多台（养老院/多老人家庭）。

## P4 · 场景扩展（决定产品天花板）

按"投入小、老人感知强"排序：

| 优先级 | 功能 | 说明 |
|---|---|---|
| 高 | 用药提醒 | 定时语音 + 大按钮"我已吃药"，未确认则短信通知家人 |
| 高 | SOS 长按音量键 | 连续按 3 次音量+ 拨第一个家人号码并发送位置 |
| 中 | 陌生号码/诈骗提醒 | 来电不在通讯录 → 播报"陌生号码，小心诈骗" |
| 中 | 使用报告 | 每天给家人一条短信：今天用了几次微信、几点睡的 |
| 低 | 语音找手机 | 家人发短信"找手机"→ 最大音量响铃 10 秒 |
| 低 | 跌倒检测 | 依赖手表/传感器，暂不碰 |

## 技术债

| 项 | 现状 | 建议 |
|---|---|---|
| 无数据层抽象 | 配置直接读写 `SharedPreferences`，键散落（已收口到 `Prefs`） | 再进一步：`Config` 对象 + JSON 序列化，便于整包导出/下发 |
| 单模块工程 | 38 个类全在 `com.elder.launcher` 包下 | 分 `core / guardian / ui / remote` 四个包，为 P3 铺路 |
| 无崩溃上报 | 崩了只能现场看 | 本地落 crash 文件，家人发"日志"短信回传关键行 |
| 无自动化测试 | 全靠手点 | uiautomator smoke：启动→点卡片→进设置→自检，10 条用例 |
| 签名用 debug 证书 | 便于覆盖升级，但不适合公开发布 | 正式分发前生成 release keystore，并保留升级路径说明 |
