# 零基础入门：这些词到底是什么意思

> 这篇**不教你操作**，只把名词讲成人话，让你知道自己在干什么、该去搜什么。
> 真要动手，请找对应关键词的**专业教程**（B 站、博客、OpenWrt 文档都行），
> 每个名词后面我都标了该搜什么。

## 先看整件事是怎么连起来的

```
老人的手机                中继                    家人的手机
（守护桌面）  ──上报──▶  （一个小程序）  ◀──查看── （家人端）
                位置/电量/状态              位置/轨迹/发指令
```

三个东西都在**你自己的控制下**，没有第三方服务器，没有账号注册。
中间的"中继"就是这个项目要你装的那一个程序。

---

## 1. 服务器

**人话**：一台**一直开着、有公网地址**的电脑，别人能通过网络找到它。

我们这里不需要多强，**1 核 1G 内存都够**（中继常驻内存约 10MB）。
它可以是：

| 形态 | 是什么 | 成本 |
|---|---|---|
| **你家的路由器** | 刷个开源系统，就能当小服务器 | 二手几十块，电费忽略 |
| **NAS** | 家里的网络硬盘（飞牛、群晖等），本来 24 小时开着 | 已有就不用额外花钱 |
| **VPS** | 网上租的云服务器 | 一年几十到几百 |

> **建议顺序**：先用手上已有的（路由器/NAS），最后才考虑买 VPS。
> 这个项目的数据不值得为它单独花钱。

🔍 该搜：`VPS 入门`、`Linux 服务器 基础命令`

---

## 2. IP、端口、域名

三个词经常一起出现，用一栋楼打比方：

| 名词 | 类比 | 例子 |
|---|---|---|
| **IP 地址** | 楼的门牌号 | `192.168.1.10`、`2408:8220:...` |
| **端口** | 门牌号后面的房间号 | 我们这个程序住 `8898` 号房 |
| **域名** | 给门牌号起的"好记的名字" | `shouhu.example.com` |

- **局域网 IP**（`192.168.x.x`）：只在家里这个 WiFi 里有效，出门就找不到。
- **公网 IP**：全世界都能找到的地址。家里宽带现在多半**没有公网 IPv4**，但有**公网 IPv6**。
- **端口**为什么重要：同一个 IP 上可以住很多服务，靠端口区分。
  所以地址要写成 `地址:8898`，冒号后面那个数字就是房间号。

🔍 该搜：`什么是 IP 地址`、`端口是什么`、`公网IP 和 内网IP 区别`

---

## 3. IPv6 和"二级域名"

**IPv6 人话**：新一代的地址，多到用不完，所以家里的宽带**通常已经有一个公网 IPv6**。
好处是：**不用做端口映射**，外面就能直接访问（前提是路由器防火墙放行）。

**二级域名人话**：别人送你一个名字，挂在你自己的地址上。
免费的有 **dynv6**、**duckdns**，能申请到 `xxx.dynv6.net` 这种。

为什么需要它：

- IP 太难记，尤其 IPv6 长得像 `2408:8220:7f10:78c0:...`；
- 家里的 IP 会变（重启光猫、运营商换前缀），域名不变，靠 DDNS 跟着变。

🔍 该搜：`家宽 IPv6 开启`、`dynv6 免费二级域名 教程`、`IPv6 防火墙 放行端口`

---

## 4. DDNS（动态域名）

**人话**：家里的 IP 变了，自动把域名指到新 IP 的服务。

"动态"是因为家里拿到的地址**会变**；DDNS 就是那个"自动改地址簿"的小助手。
这个项目里已经内置了 **Dynv6 和 Cloudflare** 的更新器——你填一次域名和令牌，它自己维护。

🔍 该搜：`DDNS 是什么`、`dynv6 token 获取`

---

## 5. 路由器 与 OpenWrt

**路由器人话**：家里网络的总闸，负责把宽带分给所有设备。
原厂固件功能很少，只能点点开关。

**OpenWrt 人话**：给路由器换一个**开源的、能装程序的系统**——相当于把路由器变成一台小电脑。
装了它，路由器就能跑我们这个中继，于是你**不用买服务器、不用开 NAS**。

这也是为什么我做了两个便宜机型的安装包：

| 机器 | 说明 | 二手价 |
|---|---|---|
| **小米路由器 mini（R1C）** | 双频、128MB 内存、带 USB，最省心 | 几十块 |
| **小米路由器 青春版（R1CL）** | 单频 2.4G、64MB 内存、USB 供电 | 更便宜 |

它们都是 16MB 存储——刚好够放下压缩后的中继（约 2MB）。
**好处**：一次性几十块，不用月租、不用买 NAS，插上就用，放老人家里也不占地方。

⚠️ **刷机有风险**：刷错会变砖（开不了机）。所以刷之前要先刷一个叫 **Breed** 的"救砖引导"。

🔍 该搜：`<你的路由器型号> OpenWrt 刷机`、`Breed 刷入 教程`、`OpenWrt sysupgrade`

---

## 6. Breed（刷机前的"保命符"）

**人话**：一个刷不死的引导程序，相当于电脑的 BIOS + U 盘 PE。
装了它，以后固件刷坏了还能进去重刷，不至于把路由器扔了。

🔍 该搜：`Breed 是什么`、`<型号> 刷 Breed`

---

## 7. ADB（电脑指挥安卓手机的那根线）

**人话**：让电脑给手机下命令的工具，走 USB（也可以走 WiFi）。
我们要用它做两件事：**把 App 装进去**、**给 App 一个特殊权限**（见下一节）。

前提是手机要打开"开发者选项"里的 **USB 调试**（在"关于手机"里连点版本号 7 次就会出现）。

🔍 该搜：`安卓 打开 USB 调试`、`adb devices`、`adb install`

---

## 8. Device Owner / 设备管理员 / 锁定任务

这是整个项目最关键、也最容易卡住的一环。

- **设备管理员（Device Admin）**：普通的管理权限，能锁屏、清数据。
- **Device Owner（设备所有者）**：更高一级。**只有它才能锁住桌面**——
  让老人按 HOME 退不出去、下拉通知栏被收起、进不了设置。
- **锁定任务（Lock Task / Kiosk）**：把手机固定在某个界面，也就是"老人机模式"。

⚠️ **厂商限制**：华为/荣耀对第三方桌面特别严，就算激活了 Device Owner，
还要手动去放行"应用启动管理""电池优化"等设置，否则会被系统悄悄杀掉。

🔍 该搜：`Device Owner 是什么`、`adb shell dpm set-device-owner`、`安卓 锁定任务模式`

---

## 9. 保活 / 省电策略（为什么夜里会"失联"）

**人话**：安卓为了省电会杀后台，国产系统杀得更狠。
表现就是：白天好好的，夜里家人端一片"离线"。

解决靠三件事：**电池优化白名单**、**允许自启动/后台活动**、**休眠时保持网络连接**。
这个是厂商的私有设置，任何 App 都绕不过去，只能手动点。

🔍 该搜：`<手机品牌> 应用启动管理`、`安卓 后台保活 白名单`

---

## 10. 内网穿透 / 反向代理（没有 IPv6 时的备选）

**人话**：家里只有内网地址，就在外面租一台有公网地址的机器**帮你转接**。

- **内网穿透**：frp、Cloudflare Tunnel 这类工具；
- **反向代理**：Nginx、Caddy 这类软件，把多个服务挂在一个域名下。

这个项目**不强依赖**它们。家里有 IPv6 + 一个免费二级域名，就够了。

🔍 该搜：`frp 内网穿透 教程`、`Cloudflare Tunnel 教程`、`Nginx 反向代理`

---

## 11. Docker

**人话**：装软件的"集装箱"。把程序连同它需要的东西打成一个包，
一条命令拉下来就能跑，不用管环境依赖。

这是部署中继**最省事**的方式，也是我推荐的第二种选择（第一种是路由器）。

🔍 该搜：`Docker 入门`、`docker compose 教程`

---

## 12. 二维码（这里用来"传配置"）

中继的设备页会给同一位老人生成**两个**二维码，各给一头扫，不用手打地址和密钥：

| 二维码 | 谁来扫 | 里面装的是什么 |
|---|---|---|
| **老人端二维码** | 老人机扫 | `https://你的地址/api/report?k=令牌` —— 一条上报地址 |
| **家人端二维码** | 家人手机扫 | `elderguard://relay?base=地址&k=令牌&n=称呼` —— 地址 + 令牌 + 称呼 |

**为什么老人端那个好扫、家人端那个容易扫不出来？** 纯粹是内容长度：

- 老人端只要一个能上报的地址，几十个字符，二维码的点阵很稀疏；
- 家人端要带协议头 `elderguard://`、还要把地址转义、再带称呼，字符多出不少，
  同样尺寸下点阵更密，镜头稍微虚一点就解不出来。

代码里为此专门砍过一个参数（家人端其实用不到设备 id，但带上会让码多出几十个字符），
就是怕手机上那张 320px 的图密到扫不动。

所以扫不出来时先分清是哪个码：

- 家人端扫码失败 → 常用解法是把手机拿远一点再对焦、擦一下镜头、调高屏幕亮度，
  或者用家人端的「**从相册选图**」——把二维码截图存相册，识别率比对着屏幕拍高很多；
- 老人端扫码失败 → 先确认中继上「二维码地址」填的是**能在外网访问到的地址**，
  没填的话中继根本不出码（会直接提示你去填）。

## 13. 安全常识（比技术更重要）

- 中继的**访问密码一定要设**：首页能看到所有老人的令牌，等于总钥匙；
- 二维码里带令牌，**别发到群里、别截图发朋友圈**；
- 家里路由器不要让中继"裸奔"在公网：至少要密码；
- 这套东西是给**自己家老人**用的，不要用在别人的设备上。

## 推荐的上手顺序（从零到能用）

1. **先不折腾外网**：手机、中继、家人端都连同一个 WiFi，用局域网 IP（`192.168.x.x:8898`）先跑通；
2. **再打通外网**：开 IPv6 + 申请一个免费二级域名（如 `xxx.dynv6.net`）+ 放行端口；
3. **然后才考虑"放哪"**：有 NAS 用 NAS（Docker 最省事）；没有就刷一台 R1C/R1CL 当小服务器；
4. **最后才考虑买 VPS**——除非你本来就有。

> 之所以按这个顺序：**先让它在家里能用，再考虑出门能用。**
> 很多人的挫败感来自"一上来就搞公网"，其实局域网阶段就能验证 90% 的功能。
