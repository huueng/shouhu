## P0 · 三条命门（不做完不算可用）

### 1. 开机自启 + 自动锁定
- **依赖**：只需重启一次手机
- **步骤**：确认设置里「锁定任务」开着 → 重启 → 等 30 秒，不要碰屏幕
- **通过标准**：开机后自动回到守护主界面，且按 HOME 键退不出去
- **失败表现**：停在华为桌面 / 回到桌面但没锁
- **排查**：`adb logcat | grep ElderBoot`

### 2. 响铃挂断 → 短信回位置（核心救命链路）
- **依赖**：**必须装 SIM 卡**（现在没卡，一直没验）
- **前置**：设置 → 家人与联系人 → 家人号码里填你另一台手机的号
- **步骤**：用另一台手机拨老人机 → **响 2 声就挂断**（别接听）→ 等 30~60 秒
- **通过标准**：老人机给你发来一条短信，含经纬度/地址 + 高德链接
- **失败表现**：
  - 完全没反应 → 看「短信定位 / 来电触发」开关是否开着、号码有没有对上
  - 收到「定位失败」→ GPS 没开或室内
- **排查**：`adb logcat | grep -E "ElderCallTrigger|ElderLocation|ElderSms"`

### 3a. 来电时是否出现通话页
- **依赖**：第二台手机（芬达）
- **状态**：**去电已修好并验证**（`InCallUI` 显示正常）；来电侧还需要你打一次确认
- **步骤**：用芬达拨老人机 → 看是否出现来电界面（有接听/挂断大按钮）
- **通过标准**：来电页正常出现，铃声只响一个、不再是两个声音叠在一起
- **排查**：`adb logcat | grep ElderAdmin`（看白名单条数）、`dumpsys activity | grep mResumedActivity`

### 3. 通话结束自动回桌面
- **依赖**：无（但要真拨一通电话，不能只开拨号盘）
- **步骤**：从电话墙点一张联系人卡 → 真的打出去 → 挂断
- **通过标准**：挂断后自动回到守护主界面（不是停在通话记录）
- **注意**：只对「从本应用拨出」生效；家人打进来不受影响
- **排查**：`adb logcat | grep ElderCallReturn`

## P1 · 没网 / 没 GPS 时的保命能力

### 4. 无网络下仍能定位并回短信
- **依赖**：SIM 卡
- **步骤**：关掉移动数据 + 关掉 WiFi → 打开定位 → 走到窗边/室外 → 响两声挂断
- **通过标准**：**60 秒内**收到位置短信；短信里只有经纬度（没中文地址属正常，无网查不到地址）
- **失败表现**：超过 60 秒没回 / 回「定位失败」
- **已知限制**：室内基本定不到，只能拿到上次缓存的位置（短信会写「最后一次已知位置」）

### 5. 短信指令
- **依赖**：SIM 卡
- **步骤**：给老人机发 `位置`；再发 `跟踪 10 30`
- **通过标准**：`位置` 回一条；`跟踪 10 30` 每 30 秒回一条、共 10 条
- **注意**：只认「家人号码」，别的号发过去无反应（这是设计）

### 6. 来电播报
- **依赖**：第二台手机
- **步骤**：另一台手机打进来，听老人机是否念「来电 妈妈」
- **通过标准**：响铃同时有语音
- **已知风险**：有些机型铃声会抢占 TTS，听不到就告诉我，改成「响铃 2 秒后再念」

## P2 · 日常体验

### 7. 通知白名单拦截
- **步骤**：让某个**不在白名单**的应用发一条通知（比如某个小工具）
- **通过标准**：老人机通知栏里看不到它；白名单里的（微信/短信）正常显示
- **注意**：需要「通知使用权」已开（自检页可查）；设置里有总开关可整体关掉

### 8. 定时清理后台
- **步骤**：设置把清理间隔调成 30 分钟 → 打开几个应用放后台 → 等一轮
- **通过标准**：后台应用被清掉，白名单里的（微信等）还在

### 9. 悬浮导航键
- **步骤**：设置 → 常用 → 打开悬浮导航键 → 点返回/主页/多任务三个圆点
- **通过标准**：三个键都能用（这是"实体键坏了"的兜底）

### 10. 电子围栏越界提醒
- **依赖**：要真的走动（≥ 设定半径）
- **步骤**：家人端给老人设 500 米围栏 → 带手机出门超过 500 米 → 点「查询位置」
- **通过标准**：页面弹出黄色「已离开围栏约 X 米」提醒
- **注意**：只有**查询时**才判断，不查不提醒（老人机不主动推流）

### 11. 家人端扫码添加
- **依赖**：第二台手机装家人端
- **步骤**：一台显示老人机「远程访问」二维码 → 另一台用「相机扫码」和「相册选图」各试一次
- **通过标准**：地址/端口/密钥自动填好，并能查到位置

### 12. 家人端地图
- **步骤**：详情页看地图是否显示中文地名（高德瓦片）
- **通过标准**：能看到街道名，定位点位置正确（不偏移）
- **注意**：Leaflet 走 CDN，首次要联网加载

### 13. 网页传包（另一台手机）
- **步骤**：老人机开「网页传包」→ 另一台手机扫二维码 → 上传一个 APK
- **通过标准**：文件进「下载 / 老人守护」，网页里能点开；手机上能点安装

### 14. 天气地点手动指定
- **步骤**：设置 → 语音与提醒 → 天气地点 → 输入「杭州」
- **通过标准**：提示"已设为：浙江 杭州"，主界面天气随之变化

## P3 · 需要额外条件

### 15. 移动数据限制（白名单之外禁止用流量）
- **依赖**：**需要一台 Android 11+ 的手机**（现在这台是 Android 10，接口不存在）
- **通过标准**：开关能打开，Toast 显示"已限制 N 个应用用移动数据"

### 16. Cloudflare + us.kg 换域名
- **依赖**：你去 us.kg 申请域名 + 建 Cloudflare API Token
- **步骤**：设置 → 远程访问 → 配置域名同步 → 服务商选 Cloudflare → 填域名/Token → 立即同步
- **通过标准**：提示"已新建 AAAA（灰云）"；`check-remote.ps1 -Domain 你的域名` 三段全绿
- **红线**：这条记录必须是**灰色云朵**，橙色云不支持 8899 端口

### 17. 移动数据下远程访问（真正的外网）
- **依赖**：SIM 卡（移动数据有公网 IPv6）
- **步骤**：拔掉 WiFi，只用流量 → 等 DDNS 更新（最多 5 分钟）→ 在外网用家人端查
- **通过标准**：能查到位置
- **注意**：家里路由器不用管这条（走的是运营商网络）；运营商是否封入站，以实测为准

## 遇到失败时给我什么

一句话现象 + 这一段日志就够：

```bash
adb logcat -d | grep -E "ElderLocation|ElderSms|ElderSmsCmd|ElderCallTrigger|ElderCallReturn|ElderDdns|ElderTrack|ElderTransfer|ElderBoot|ElderNav|ElderNotif|TtsHelper"
```

各模块对应的 TAG：

| TAG | 负责什么 |
|---|---|
| `ElderLocation` | 定位取点、离线等待、短信内容 |
| `ElderSms` | 短信指令解析与发送 |
| `ElderCallTrigger` | 来电播报、响铃挂断判定 |
| `ElderCallReturn` | 通话结束回桌面 |
| `ElderDdns` | 域名同步 |
| `ElderTrack` | 轨迹采样 |
| `ElderTransfer` | 网页传包 |
| `ElderBoot` | 开机自启、定时任务恢复 |
| `ElderNav` | 悬浮导航键 |
| `ElderNotif` | 通知白名单拦截 |
| `TtsHelper` | 语音播报（念时间/来电/天气） |
| `ElderTrackTick` | 轨迹采样心跳 |

## 建议的最小验证路径（半小时）

如果只有半小时，就按这个顺序，能覆盖 80% 的风险：

0. **用芬达打一次电话**（验来电页 + 铃声/播报不再打架）
1. **重启一次**（验开机自启 + 自动锁定）
2. **插卡，响两声挂断**（验核心救命链路，含短信）
3. **打一通电话再挂断**（验回桌面）
4. **关数据+WiFi，走到室外，再响两声**（验无网定位）
5. 手边有第二台手机就顺手验**家人端扫码 + 来电播报**

做完这 5 条，剩下的都是"锦上添花"，可以慢慢来。
